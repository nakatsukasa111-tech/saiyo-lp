# assets / 画像アップロードガイド

このフォルダに画像ファイルを置くと、LPに自動で反映されます。
**ファイル名は下記と合わせてください**（大文字小文字も一致させる）。

## 必要な画像一覧

| ファイル名 | 用途 | 推奨サイズ |
| --- | --- | --- |
| `logo.png` （またはSVG） | ヘッダー・フッターのロゴ | 高さ 80px 以上、透過PNG推奨 |
| `hero.jpg` | ヒーロー背景（トップの大きな写真） | 横 1920 × 縦 1080 px 以上 |
| `feature1.jpg` | 特徴01（トレーナー指導風景） | 横 800 × 縦 600 px |
| `feature2.jpg` | 特徴02（独自メソッド実施中） | 横 800 × 縦 600 px |
| `feature3.jpg` | 特徴03（お客様との対話） | 横 800 × 縦 600 px |
| `ceo.jpg` | 代表メッセージの写真 | 横 600 × 縦 800 px |

## アップロードのしかた（GitHubブラウザ上）

1. GitHubで対象ブランチを開く
2. `assets` フォルダをクリック
3. 右上 **「Add file」→「Upload files」**
4. 画像をドラッグ＆ドロップ
5. 下部の **「Commit changes」** をクリック

画像がない箇所は、CSSで用意された青のプレースホルダが表示されます。
画像を追加すれば、JavaScriptが自動で背景に設定します（リロード不要の場合あり）。

## ロゴを使わない場合

`logo.png` が存在しない場合、自動で「**NeeDS**」というテキストロゴにフォールバックします。
